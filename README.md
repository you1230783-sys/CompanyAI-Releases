# CompanyAI Releases

CompanyAI 的公開安裝包下載區，支援 Windows 11 x64。

[下載最新版安裝包](https://github.com/you1230783-sys/CompanyAI-Releases/releases/latest/download/LM_AI_Setup.exe) · [所有版本](https://github.com/you1230783-sys/CompanyAI-Releases/releases)

請先從系統托盤離開程式，再執行安裝包。安裝位置固定為 `C:\largan\LM_AI`；Microsoft WebView2 Runtime 需另外安裝。

每版 Release 提供 `LM_AI_Setup.exe` 與對應的 `update-manifest.json`，檔案大小與 SHA-256 列於該版說明。

## 0.9.54 更新內容

- 修正「從 Outlook 帶入」的稱呼一閃就消失，現在會保留到按下保存。
- 稱呼欄中尚未保存的文字，不會再因畫面更新而被清掉。

## 0.9.53 更新內容

- 信件分頁可手動或每 20 分鐘掃描 Outlook，找到的事項放在待確認。
- 掃描來的事項可「查看原始信件」，稱呼可從 Outlook 名稱自動帶入。
- 工作待辦可依週與日勾選事項，匯出清單、看板、四象限、甘特圖或心智圖 JPG。
- 取字快捷鍵取到文字後，可選擇貼到快速對話或加入工作待辦。

## 0.9.52 更新內容

- 工作待辦新增「信件」分頁，可設定我的稱呼並貼上信件試解析。
- 可辨識公司日期格式 MMDDYY 及常見的 MMDD、MM/DD、MM.DD 寫法。
- 自動掃描需先同意說明；連接真實信箱將在下一版開放。
- 專案對話不再顯示重複的 Outlook 助理按鈕，請改用進階功能。

## 0.9.51 更新內容（包含在 0.9.52 安裝包）

- 新增甘特圖，依開始日與截止日顯示時程，並標出今天與過期事項。
- 新增流程圖，可為事項畫 Mermaid 流程圖、預覽並匯出 SVG。

## 0.9.50 更新內容（包含在 0.9.52 安裝包）

- 新增四象限，依重要與緊急分類，快到期的事項可自動算緊急。
- 新增心智圖，可收合展開，拖曳節點即可換上層或調整順序。
- 待辦清單的大綱也能拖曳調整層級與順序。
- 可把事項送 AI 拆成子任務，結果先放在「待確認」由你決定。

## 0.9.49 更新內容（包含在 0.9.52 安裝包）

- 提醒事項升級為「工作待辦」，有待辦清單、看板、待確認與提醒分頁。
- 輸入框新增「加入待辦」，Win+Space 帶入的文字可直接存成待辦。
- 側欄固定顯示「進階功能」，集中 Outlook 助理、影像對照與工作待辦。
- 設定可匯出以密碼加密的備份，換電腦後匯入即可沿用設定與待辦。

## 0.9.48 更新內容（包含在 0.9.52 安裝包）

- 螢幕鎖定期間到期的提醒，解鎖後會重新跳出，並可延後 10 分鐘。
- 有提醒到期時鈴鐺會變紅提示，主畫面也會跳出提醒視窗。
- 晚間批次佇列重新整理版面，可單獨移除、標為完成或一次清除。
- 回覆中的命令列會自動顯示成程式碼框，通知也會跟隨主要顏色。

## 0.9.47 更新內容

- 專案對話的思考開關移到模型選單旁，可選自動、開啟或關閉。
- 選「自動」時會先判斷問題難度，簡單的任務不使用思考，回覆更快。
- 自動判斷的結果會顯示在任務的活動紀錄與摘要中。
- 網站更新後續接先前暫停的專案任務，不再直接失敗。

## 0.9.46 更新內容

- 外觀可選主題（現代、簡潔、像素）、主要顏色與深色模式；預設為暖色的「現代」。
- 專案回覆下方的工具、交付、分析合併成一列膠囊，點一下才展開明細。
- 提醒事項到期後會留在鈴鐺通知中心，按「知道了」才移除。
- 提醒的跳出通知改為醒目的紅色並持續顯示，手動關閉才會消失。

## 0.9.45 更新內容

- 搜尋區與定位標預設改為切換圖片時顯示 1 秒。
- 旋轉時整張圖直接轉動，產品與搜尋圈大小不再因旋轉而縮小。

## 0.9.44 更新內容

- 第一個圓畫完可拖曳上下左右調整、拖曳圓內移動，再張開第二個圓。
- 改為記下 Mark 的形狀後比對相似目標，自動找 Mark 更準確。
- 不常用的選項移到「進階設定」，搜尋區與定位標可選擇顯示方式。
- 載入後可收合設定區與清單；「點 Mark」按兩下可每張連續點選。

## 0.9.43 更新內容

- 影像對照新增旋轉：畫兩個同心圓作為搜尋區域並點選 Mark，之後每張自動找 Mark 並旋轉。
- 找不到 Mark 時改為點擊 Mark 位置，依位置計算角度後旋轉。
- 可選擇把 Mark 轉到最上、最下、最左或最右，A／B／C 各自決定是否旋轉。
- 也可用 ⟲ ⟳ 自訂角度旋轉；標記時一併記錄各欄的旋轉角度。

## 0.9.42 更新內容

- 進階功能新增「影像對照」：A／B／C 欄位可放資料夾或單張標準品，依檔名配對後同步縮放、平移並以按鍵標記。
- 標記存成 review_marks.csv，優先放影像資料夾；再次載入時會詢問是否讀入上一次的標記。
- 16 位元影像可勾選「將亮度調整相同」，方便比較各欄明暗。
- 「我的工作區」移到專案視窗，按「快速建立我的工作區」即可建立；同名時自動改為「我的工作區(1)」等。

## 0.9.41 更新內容

- 安全性更新。

## 0.9.40 更新內容

- 新增標準卡片、極簡卡片及氣泡通知，可從設定立即測試。
- 可調整透明度、文字大小與顯示時間；預設 3 秒，0 秒持續顯示直到手動關閉。
- 多則通知可展開查看，並在重疊時避開桌寵；未讀紅點可依位置分別開關。
- 版本停止支援時立即提示更新，先下載並驗證，經使用者同意後才安裝。
